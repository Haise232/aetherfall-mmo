# Agentes instalados

Volver al [[Índice de memoria|índice]]. Origen: repositorio VoltAgent/awesome-claude-code-subagents, copiados sin modificar.

## Solicitados

- **game-developer**: sistemas de juego, render y networking multijugador.
- **websocket-engineer**: comunicación en tiempo real con WebSockets.
- **typescript-pro**: tipos avanzados y seguridad de tipos end-to-end en el monorepo.
- **backend-developer**: APIs y servicios del servidor.
- **postgres-pro**: optimización, replicación y backups de PostgreSQL.
- **frontend-developer**: aplicaciones de frontend (enfoque React/Vue/Angular).
- **security-engineer**: seguridad de infraestructura y controles en CI/CD.
- **performance-engineer**: cuellos de botella en apps, base de datos e infraestructura.
- **qa-expert**: estrategia de QA y planes de pruebas.
- **devops-engineer**: CI/CD, contenedores y despliegues.
- **ui-designer**: diseño visual y componentes de interfaz.
- **database-optimizer**: consultas lentas e índices.
- **fullstack-developer**: funcionalidades que cruzan base de datos, API y frontend.

## Extras

- **security-auditor**: auditorías de vulnerabilidades (solo lectura). Útil para anti-cheat y servidor autoritativo.
- **fintech-engineer**: transacciones con precisión contable. Útil para el ledger de la economía del juego.
- **knowledge-synthesizer**: documenta hallazgos a partir de registros e historial de trabajo de otros agentes.
